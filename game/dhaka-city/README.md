# Dhaka Rush V3 — Mobile Touch Edition

An original open-world browser game prototype inspired by Bangladeshi city life. Built with HTML, CSS, JavaScript and Three.js WebGPU renderer.

## Mobile controls

- Left joystick: Move or drive
- Drag anywhere on the screen: Rotate camera
- দৌড়: Run while held
- মার: Punch nearby NPC
- কথা: Talk to nearby NPC
- ঢুকুন: Enter a nearby shop or building door
- গাড়ি: Enter or exit a nearby rickshaw
- হর্ন: Blow the rickshaw horn

## New in V3

- Touch camera rotation
- Enterable shops and building doors
- Drivable rickshaws
- Enter and exit vehicle system
- Improved 2K-quality rendering target
- Mobile-first UI and safe-area support

## Quality

The game targets device pixel ratio up to 2x, which is commonly called 2K-quality rendering on many phones. It automatically adapts when the phone screen changes size or orientation.

## Run locally

```bash
npx serve .
```

Open the local URL on your phone using the same Wi-Fi network, or deploy it to GitHub Pages.

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to Settings → Pages.
4. Select branch: `main`, folder: `/ (root)`.
5. Save and open the GitHub Pages URL on your phone.
