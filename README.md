# FEXO HUB 🚀

A modern, neon-styled single-page shopping website with a built-in admin panel, Google login, cart, sponsor tiers, and background music.

## ✨ Features

### Customer Side
- 🎨 **Modern Neon UI** — Glassmorphism + cyberpunk vibes
- 🖼️ **Beautiful product grid** with hover animations
- 🔍 **Live search** by product name
- 🛒 **Shopping cart** (requires Google login to order)
- 👤 **Google Sign-In** for authentication
- 🎵 **Background music** player
- 💎 **Sponsor page** with 3 tiers (Silver / Gold / Platinum)
- 📱 **Fully responsive** (mobile/tablet/desktop)
- 👀 Browse without login, order requires Google sign-in

### Admin Side (Password Protected)
- 🔐 Admin panel with password (`admin123` by default)
- 📁 **Add / Delete Topics** (unlimited)
- 📦 **Add / Delete Products** (unlimited images per product)
- 💰 Set product price, description, discount badges
- 🎵 **Manage music tracks**
- 📤 **Export/Import** data as JSON backup
- 🔑 **Change admin password**
